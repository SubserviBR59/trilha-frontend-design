# trilha-frontend-design-experiencia

# Sobre o projeto

Aplicação que utiliza Inteligência Artificial para verificar informações encontradas na internet.
O usuário pode enviar textos, imagens, vídeos ou perguntas.
A IA analisa o conteúdo e apresenta fontes e evidências para auxiliar na verificação.

# Problema

Usuários têm dificuldade para identificar informações verdadeiras e fontes confiáveis na internet.
A grande quantidade de conteúdos dificulta a verificação de notícias, imagens e vídeos.
Isso gera dúvidas e perda de tempo na busca por informações confiáveis.

# Solução proposta

Um chatbot inteligente que analisa diferentes tipos de conteúdos enviados pelo usuário.
A IA cruza informações com fontes relevantes para verificar sua confiabilidade.
Ao final, apresenta o resultado da análise acompanhado de evidências.

# Telas desenvolvidas

* Página Inicial
* Chatbot / Tela de Conversa
* Envio de Imagem
* Envio de Vídeo
* Campo de Perguntas
* Resultado da Análise
* Apresentação de Evidências
* Geração de Relatório
